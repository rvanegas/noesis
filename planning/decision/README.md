# Decisions

What was built and why, including what was deliberately not built. History,
not work: read it when something in the code is inexplicable and knowing why
would change what you do, matching filenames first. One file per decision,
named `<date>-<slug>.md`; `ts note new decision "Some Title"` makes one.

`archive/SERVER.md` is the record of moving noesis (then mdc) onto the
`commons` box, phase by phase, 2026-10-24 to 2026-11-01, frozen. **The code
cites it throughout as `SERVER.md`** (*SERVER.md, Phase 6*; *SERVER.md,
Library layout*): those citations mean this file, and are not rewritten. Its
*Where things live* and *Library layout* sections still describe noesis as
built. Go to its headings (`grep -n '^## ' archive/SERVER.md`) rather than
reading it whole.
