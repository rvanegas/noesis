# Planning

Everything about noesis that is not code and not the agent instructions
(`CLAUDE.md`), laid out as technosophia's `PLANNING.md` says. Each directory
holds items, one file each; its `README.md` is its convention.

- **`task/`**: the roadmap. Features, audits, open questions.
- **`backlog/`**: what is known and not done.
- **`decision/`**: what was built and why, one dated file per decision;
  `decision/archive/SERVER.md` is the record the code cites as `SERVER.md`.

No standing documents yet. When one is added at this level, list it here in
the same commit.
