Your first library

A library is where your writing lives on noesis: your chats and documents, and the sources they cite. noesis checks and indexes it, and Claude reads it through noesis’s tools. Start with one; you can make more later.

New library

Your names

The headings in your chats that are you, besides Prompt: in a chat from The Floor, the name you spoke under. Everywhere else in a chat is someone else, Claude or another person. Indexing and Claude’s reading of your library go by these.

Import

A chat or a document in Markdown or text, or a claude.ai export (its zip or conversations.json). It is checked and repaired as Fix would; a chat that cannot be repaired comes in as a document. Each lands in its year’s directory.

Draft its document in Claude

Claude reads from this library and writes its document with you: the position the conversation came to, in your words. Then it comes back here as the chat's pair.

  1. Be signed in to claude.ai, with the noesis connector enabled (Settings → Connectors, at https://noesis.rvanegas.co/mcp), signed in as the owner of this library, so Claude can read the chat.
  2. Open claude.ai starts a conversation with the prompt below. If the prompt is not filled in, Copy the prompt and paste it.
  3. When the document is done, download it as Markdown (or save it as a .md file).
  4. Back here, open the chat and choose Import its document.
